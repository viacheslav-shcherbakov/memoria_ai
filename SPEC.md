# Memoria — Личная память

## Описание

Мобильное PWA-приложение для хранения текстовых воспоминаний с поиском, тегами, проектами и AI-аналитикой.

## Функциональность

### Базовая
- Создание воспоминаний (текст, тема, дата, теги)
- Поиск по ключевым словам с подсветкой совпадений
- Облако тегов для фильтрации
- Карточный интерфейс с раскрытием
- Группировка по проектам
- Оффлайн работа через Service Worker
- Локальное хранение в IndexedDB (v2)

### AI (локальный, без сервера)
- Автоматическое тегирование (TF-IDF, TextRank)
- Анализ настроения (сентимент-анализ)
- Суммаризация длинных записей
- Извлечение ключевых слов
- Всё работает в Web Worker — не блокирует UI

### Аналитика
- Отчёты по проектам (настроения, теги, таймлайн)
- Еженедельный дайджест
- Инсайты на основе данных
- Распределение настроений по периодам

## UI/UX

### Текущий дизайн
- Тёмная тема (Amber/Orange акцент)
- Карточки с датой, темой, настроением
- Expandable карточки с AI-summary
- Поиск в верхней панели
- FAB для добавления нового воспоминания

### Тёмная тема (по умолчанию)
- Фон: stone-900 (#1c1917) / darker: #0c0a09
- Карточки: stone-800 (#292524)
- Акцент: orange-600 (#ea580c) → orange-500 (#f97316)
- Текст: stone-100 / stone-400

### Светлая тема
- Фон: stone-100 (#f5f5f4)
- Карточки: white (#ffffff)
- Акцент: orange-600 (#ea580c)
- Текст: stone-900 / stone-500
- Авто-определение: prefers-color-scheme при первом визите
- Переключение: кнопка 🌙/☀️ в шапке или toggle в настройках
- Хранение: localStorage key "memoria-dark-mode"

## Технологии

- Vanilla JS + ES6
- IndexedDB (v2, с индексами для projectId/mood)
- TailwindCSS (CDN, dark: модификаторы)
- Service Worker (v2, с оффлайн кэшем)
- Web Worker (для AI)
- Touch Events (для свайпов)
