3. **Смена устройства** — данные не перенесли

## 3. Tech Lead ⚙️

### Варианты локальных LLM

#### Опция A: Transformers.js (рекомендую)

```javascript
// Пример интеграции
import { pipeline } from '@xenova/transformers';

const classifier = await pipeline(
  'zero-shot-classification',
  'Xenova/mobilebert-uncased-mnli',
  { quantized: true } // ~25MB
);

// Автотеггинг
const candidateTags = ['работа', 'семья', 'путешествие', 'еда', 'мысли'];
const result = await classifier(text, candidateTags);
```

| Плюс | Минус |
|------|-------|
| Работает в вебе | Медленно на CPU |
| Модели до 100MB | Нужен Web Workers |
| Кэшируется в Cache API | Первый запуск долгий |

#### Опция B: ONNX Runtime Web + quantized models

- DistilBERT для классификации (~60MB)
- BART/T5 для суммаризации (~250MB)

#### Опция C: llama.cpp (wasm) — слишком тяжело

- Даже 1B модель = 500MB+
- Не для мобильных
- **Отклонено**

### Архитектурное решение

```
┌─────────────────────────────────────┐
│         Service Worker              │
│    (кэш моделей + оффлайн)          │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│            Web Worker               │
│   (inference, не блокирует UI)      │
└────────────────┬────────────────────┘
                 │
┌────────────────▼────────────────────┐
│         Main Thread (UI)            │
│   - Редактор текста                 │
│   - Отображение карточек            │
│   - Прогресс-бар загрузки модели    │
└─────────────────────────────────────┘
```

### Флоу AI-обработки

```javascript
// При сохранении записи
async function saveMemoryWithAI(memory) {
  // 1. Сохраняем сразу (быстро)
  await DB.add(memory);
  
  // 2. Проверяем поддержку AI
  if (aiEnabled && navigator.hardwareConcurrency > 2) {
    // 3. Запускаем в Web Worker
    const tags = await aiWorker.extractTags(memory.content);
    const summary = memory.content.length > 500 
      ? await aiWorker.summarize(memory.content)
      : null;
    
    // 4. Обновляем запись
    await DB.update({ ...memory, aiTags: tags, summary });
  }
}
```

### Graceful Degradation

```javascript
const supportsAI = () => {
  return (
    'storage' in navigator &&
    navigator.storage.estimate().then(e => e.quota > 500 * 1024 * 1024) &&
    navigator.hardwareConcurrency >= 2 &&
    !isMobileData() // не грузить модели на мобильном интернете
  );
};
```

### Технические рекомендации

1. **Web Workers обязательно** — инференс блокирует UI на 2-5 сек
2. **Progressive loading:** показывать % загрузки модели на первом старте
3. **Cache-first:** модель кэшируется в Cache API (не в IndexedDB)
4. **Battery-aware:** не запускать AI если батарея < 20%
